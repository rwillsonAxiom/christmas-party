Focused dependency review: @paulmillr/qr 0.7.2 from JSR
Reviewed 12 November 2026

Scope: published index.ts (encoder), decode.ts (decoder), dom.ts (optional
camera/DOM helpers), import graph, argument validation, SVG generation,
camera lifecycle and browser side effects. This is a focused manual review
and targeted search, not a complete line-by-line mathematical audit, fuzzing
campaign or security certification. It does not cover future releases.

Findings:
- No external dependencies in the published module graph.
- No runtime network calls, analytics, storage access, dynamic imports,
  eval/new Function or automatic navigation found in these three modules.
  The fetch() match in dom.ts is a documentation example, not runtime code.
- Importing the encoder/decoder does not request camera permission.
- The decoder validates integer dimensions, buffer layout and lengths;
  limits dimensions to 4096 per side and its input arena to 64 MiB.
- Encoder payload capacity and output dimensions are checked. SVG rendering
  produces numeric QR geometry rather than inserting the payload as HTML.
- Decoder retry time/effort controls are not a hard CPU deadline for the
  complete operation.
- Optional DOM helpers retain camera/image resources until stop/clear.
  QRCanvas reserves a large capacity by default. The optional svgToPng
  parses SVG; it is not a sanitizer for arbitrary markup.

Integration decisions:
- Pin 0.7.2 and retain Deno lockfile integrity checks.
- Import only encoder/decoder into production, not the optional DOM helpers.
- Request video only after a button click, limit frames to 800x800 and scan
  frequency, and stop media tracks on exit. Frames stay in the browser.
- Decode only pixels inside the inner scan overlay, capped at 800x800.
- Decode with effort=1 and timeLimit=8. Use native multi-code detection or
  decodeQRBatch with its capacity bounded to the cropped frame. Use successful
  results' corner coordinates to draw selectable name labels; reject projected
  corners outside the scanned region. Keep scanning after selection.
- Treat decoded text as untrusted: extract an account UUID from a recognised
  URL shape, never navigate to the scanned URL or insert it as HTML.
- Require server-side staff sessions for every credit change.
- Review upgrades explicitly. These checks cannot prove absence of bugs.
